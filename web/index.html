Browserintegration

Dieses Dashboard steuert keine fremden Tabs. Echte Fortsetzungen starten und stoppen ausschließlich über das RED-Loop-Panel auf chatgpt.com.

  1. Safari auf iPhone, iPad oder Mac: das Userscript mit der separat installierten Userscripts-Erweiterung importieren. Alternativ die native RED-Loop-App mit Safari-Erweiterung bauen und installieren.
  2. Windows: das Userscript in einem kompatiblen Userscript-Manager für Edge, Chrome oder Firefox importieren. Die Erweiterungsressourcen liegen außerdem im Repository für einen lokalen Entwicklertest.
  3. RED Loop Userscript herunterladen und nur für https://chatgpt.com/* freigeben.
  4. Eine bestehende Konversation mit einer Antwort öffnen, ein kleines Limit wählen und im RED-Loop-Panel Start drücken.

Das Panel stoppt bei Entwürfen, Fehlern, Tabwechsel und Navigation. ChatGPT muss sichtbar bleiben. Eingaben werden nie überschrieben. DOM-Änderungen können die Integration unterbrechen; echte Geräteprüfungen stehen aus.

Native iPhone-App

Der SwiftUI-Host bietet eine eigenständige Demo und Aktivierungshilfe. Seine Starttaste steuert keinen Safari-Tab. Nach Installation: Einstellungen → Apps → Safari → Erweiterungen → RED Loop aktivieren, dann den Website-Zugriff auf chatgpt.com erlauben. Bei älteren iOS-Versionen liegt Safari direkt in Einstellungen.

Daten und Kontrolle

Demo-Nachrichten, Zähler und Aktivitätsprotokoll bleiben im Arbeitsspeicher dieses Tabs. Beim Neuladen werden sie gelöscht. Nur deine Darstellungswahl wird lokal gespeichert.

Das Dashboard fragt keine ChatGPT-Zugangsdaten ab und sendet keine Konversationen an Cloudflare. Der Hostinganbieter verarbeitet technisch notwendige Webanfragen; Worker-Protokolle können Request-Metadaten enthalten.

Das Userscript liest den sichtbaren Antwortzustand lokal und speichert nur Zähler und Limits pro Konversation im Sitzungsspeicher. Es verschickt auf deinen Start hin begrenzte Fortsetzungsnachrichten über die ChatGPT-Oberfläche. Die Nutzung erfolgt unter den dort geltenden Bedingungen und Limits.

Kein Hintergrunddienst, keine Ausführung bei gesperrtem iPhone, keine Garantie bei Änderungen der ChatGPT-Oberfläche. Stopp bleibt im Panel erreichbar.
