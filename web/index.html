        02 — DEIN RAHMEN BLEIBT
        Cloud-Aufträge laufen serverseitig weiter, auch wenn du den Tab schließt oder die Anzeigeaktualisierung pausierst. Nutze „Auftrag pausieren“ oder „Auftrag stoppen“, um die Ausführung anzuhalten. Die lokale Demo bleibt ausschließlich in deinem Browser.
        

        DIREKT IM BROWSER
        Dein Chat.
        Deine Freigabe.
        Windows: Edge und Chrome
        Die Erweiterung funktioniert ohne Userscript-Manager. Dieses Entwicklerpaket wird lokal geladen und ist noch kein Store-Eintrag.
        Windows-Erweiterung herunterladen ↓
        1. ZIP vollständig in einen festen Ordner entpacken.
        2. edge://extensions oder chrome://extensions öffnen und Entwicklermodus aktivieren.
        3. Entpackte Erweiterung laden wählen und den Ordner mit manifest.json auswählen.
        4. Eine bestehende ChatGPT-Konversation neu laden. Im RED-Loop-Panel deinen Text unter Automatischer Folgetext eintragen, ein kleines Limit wählen und Start drücken. Nach jeder fertigen Antwort wird der Text erneut gesendet.
        Der entpackte Ordner muss erhalten bleiben. Bei Firmenbrowsern kann eine Richtlinie die Installation verhindern.
        Safari: iPhone, iPad und Mac
        Das RED Loop Userscript mit der separat installierten Userscripts-Erweiterung importieren. Alternativ die native RED-Loop-App mit Safari-Erweiterung bauen und installieren. Zugriff nur für https://chatgpt.com/* erlauben.
        Deine Kontrolle
        Dieses Dashboard steuert keine fremden Tabs. Fortsetzungen in ChatGPT starten und stoppen ausschließlich über das RED-Loop-Panel auf chatgpt.com. Das Panel stoppt bei Entwürfen, Fehlern und Navigation. Für Windows kann „Auch im Hintergrund weiterarbeiten“ aktiviert werden. Für offene Aufträge „Text für offene Aufgaben laden“ wählen; Browser offen und PC wach halten. Ohne Hintergrundmodus stoppt der Loop bei Tabwechsel. In Edge chatgpt.com unter „Diese Websites immer aktiv halten“ eintragen, damit der Tab nicht schläft. Eingaben werden nie überschrieben. DOM-Änderungen können die Integration unterbrechen. Windows Edge wurde mit einer echten Testkonversation geprüft; die Abdeckung weiterer Geräte steht im Testbericht.
        ChatGPT öffnen ↗
        Native iPhone-App
        Der SwiftUI-Host bietet eine eigenständige Demo und Aktivierungshilfe. Seine Starttaste steuert keinen Safari-Tab. Nach Installation: Einstellungen → Apps → Safari → Erweiterungen → RED Loop aktivieren, dann den Website-Zugriff auf chatgpt.com erlauben. Bei älteren iOS-Versionen liegt Safari direkt in Einstellungen.
        

        KLARE GRENZEN
        Privat.
        Von Anfang an.
        Daten und Kontrolle
        Demo-Nachrichten, Zähler und Aktivitätsprotokoll bleiben im Arbeitsspeicher dieses Tabs. Beim Neuladen werden sie gelöscht. Nur deine Darstellungswahl wird lokal gespeichert.
        Die lokale Demo fragt keine Zugangsdaten ab und sendet keine Demo-Inhalte an Cloudflare. Cloud-Aufträge verwenden einen privaten RED-Loop-Zugangstoken, der ausschließlich im Arbeitsspeicher des Tabs bleibt und im Authorization-Header an diesen Dienst gesendet wird. Titel, Auftrag, Schritte und Datei-Artefakte werden auf dem Server gespeichert und für die Ausführung an den eingerichteten KI-Anbieter übermittelt. Öffentliche Dokumentationsrecherche kann externe Webseiten aufrufen. Cloud-Aufträge laufen unabhängig vom geöffneten Browser weiter; Abmelden löscht keine Serverdaten und stoppt keine Aufträge. Der Hostinganbieter verarbeitet technisch notwendige Webanfragen; Worker-Protokolle können Request-Metadaten enthalten.
        Das Userscript liest den sichtbaren Antwortzustand lokal und speichert Zähler, Limits, deinen Folgetext und die Hintergrund-Einstellung pro Konversation im Sitzungsspeicher dieses Browser-Tabs. Es verschickt auf deinen Start hin begrenzte Fortsetzungsnachrichten über die ChatGPT-Oberfläche. Die Nutzung erfolgt unter den dort geltenden Bedingungen und Limits.
        Die Browser-Integration ist kein Hintergrunddienst und läuft nicht bei gesperrtem iPhone. Änderungen der ChatGPT-Oberfläche können sie unterbrechen. Cloud-Aufträge arbeiten separat serverseitig innerhalb ihrer Schritt- und Zeitlimits. Stopp bleibt im Panel erreichbar.
