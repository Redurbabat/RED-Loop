Windows: Edge und Chrome

Die Erweiterung funktioniert ohne Userscript-Manager. Dieses Entwicklerpaket wird lokal geladen und ist noch kein Store-Eintrag.

Windows-Erweiterung herunterladen ↓

  1. ZIP vollständig in einen festen Ordner entpacken.
  2. edge://extensions oder chrome://extensions öffnen und Entwicklermodus aktivieren.
  3. Entpackte Erweiterung laden wählen und den Ordner mit manifest.json auswählen.
  4. Eine bestehende ChatGPT-Konversation neu laden. Im RED-Loop-Panel deinen Text unter Automatischer Folgetext eintragen, ein kleines Limit wählen und Start drücken. Nach jeder fertigen Antwort wird der Text erneut gesendet.

Der entpackte Ordner muss erhalten bleiben. Bei Firmenbrowsern kann eine Richtlinie die Installation verhindern.

Safari: iPhone, iPad und Mac

Das RED Loop Userscript mit der separat installierten Userscripts-Erweiterung importieren. Alternativ die native RED-Loop-App mit Safari-Erweiterung bauen und installieren. Zugriff nur für https://chatgpt.com/* erlauben.

Deine Kontrolle

Dieses Dashboard steuert keine fremden Tabs. Echte Fortsetzungen starten und stoppen ausschließlich über das RED-Loop-Panel auf chatgpt.com. Das Panel stoppt bei Entwürfen, Fehlern, Tabwechsel und Navigation. ChatGPT muss sichtbar bleiben. Eingaben werden nie überschrieben. DOM-Änderungen können die Integration unterbrechen. Windows Edge wurde mit einer echten Testkonversation geprüft; die Abdeckung weiterer Geräte steht im Testbericht.

ChatGPT öffnen ↗

Native iPhone-App

Der SwiftUI-Host bietet eine eigenständige Demo und Aktivierungshilfe. Seine Starttaste steuert keinen Safari-Tab. Nach Installation: Einstellungen → Apps → Safari → Erweiterungen → RED Loop aktivieren, dann den Website-Zugriff auf chatgpt.com erlauben. Bei älteren iOS-Versionen liegt Safari direkt in Einstellungen.

Daten und Kontrolle

Demo-Nachrichten, Zähler und Aktivitätsprotokoll bleiben im Arbeitsspeicher dieses Tabs. Beim Neuladen werden sie gelöscht. Nur deine Darstellungswahl wird lokal gespeichert.

Das Dashboard fragt keine ChatGPT-Zugangsdaten ab und sendet keine Konversationen an Cloudflare. Der Hostinganbieter verarbeitet technisch notwendige Webanfragen; Worker-Protokolle können Request-Metadaten enthalten.

Das Userscript liest den sichtbaren Antwortzustand lokal und speichert Zähler, Limits und deinen gewählten Folgetext pro Konversation im Sitzungsspeicher dieses Browser-Tabs. Es verschickt auf deinen Start hin begrenzte Fortsetzungsnachrichten über die ChatGPT-Oberfläche. Die Nutzung erfolgt unter den dort geltenden Bedingungen und Limits.

Kein Hintergrunddienst, keine Ausführung bei gesperrtem iPhone, keine Garantie bei Änderungen der ChatGPT-Oberfläche. Stopp bleibt im Panel erreichbar.
