# RED MORPH — OPTICAL GLASS & INTELLIGENT MOTION

The supplied RED Morph brief selects the functional, quiet optical-glass direction for this implementation. The mark is a typographic R; no external brand artwork was supplied.

| Token | Light | Dark |
|---|---|---|
| Canvas | `#F4F2EE` | `#1C1C20` |
| Primary text | `#27282D` | `#F1EEEB` |
| Secondary text | `#65646C` | `#B1ACB2` |
| RED accent | `#A9233B` | `#F18B9C` |
| Secondary surface | `#F4E9E8` | `#453039` |

- System typography on each platform; monospaced metadata and tabular counters.
- 8pt spacing rhythm, 24pt panels, 44pt minimum primary controls.
- Fine, directional reflective edges; readable surfaces with restrained material blur.
- Red indicates intentional action/status, without continuous glow.
- Short, interruptible state changes; native numeric morph and spring transitions.
- Reduced Motion disables nonessential transitions on web and native app.
- Native layout adapts to Dynamic Type with vertical action fallback; web switches from two columns to one below 700px.
- Light/dark previews for iPhone, iPad, MacBook and Windows are captured from the actual web app, not native device screenshots.
